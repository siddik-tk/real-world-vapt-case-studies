# Real-World VAPT Case Studies

This repository contains a collection of real-world security findings identified during hands-on penetration testing of web, API, and mobile applications.

The focus is on practical vulnerabilities involving authentication, session handling, and business logic rather than theoretical issues.

## Included Case Studies

- Authentication state desynchronization (2FA bypass)
- Access to protected endpoints before OTP verification
- Session management flaws (token valid after logout)
- Race condition in account creation
- API logic flaws (invalid input handling)
- Information disclosure (VDP validated P1)

## What This Shows

- Real testing methodology (not just tools)
- Understanding of authentication and authorization flows
- Ability to identify business logic vulnerabilities
- Experience writing structured security findings

## Note

All write-ups are based on real testing experience.

Sensitive details such as:
- target domains
- tokens
- user data

have been removed or modified.

Detailed reports can be discussed during interviews.
