Real-World VAPT Case Studies

This repository showcases real-world vulnerabilities identified during hands-on penetration testing of web, API, and mobile applications.

Focus Areas:
- Authentication & Authorization flaws
- Session management issues
- Business logic vulnerabilities

Key Findings:
- 2FA bypass via authentication state desynchronization
- OTP verification bypass (pre-verification token abuse)
- Race condition in account creation
- Session persistence after logout
- API validation flaws
- Critical information disclosure (Bugcrowd P1)

What this demonstrates:
- Real-world testing methodology
- Strong understanding of authentication flows
- Ability to identify and analyze business logic flaws
- Professional vulnerability reporting skills

Note:
All sensitive data has been removed or modified.
Detailed reports can be discussed during interviews.
